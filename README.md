# 24hr Story Feature

A client-side Instagram/WhatsApp-style story feature built with HTML, CSS and vanilla JavaScript.

**Live demo:** https://yadukrishnach.github.io/story-feature/
**Project URL: ** https://github.com/YadukrishnaCH/story-feature


## Features
- Plus button to upload an image
- Images resized to fit within 1080x1920, converted to base64 and saved in localStorage
- Stories expire automatically after 24 hours
- Full-screen viewer with auto-advance, swipe, tap and keyboard navigation
- Responsive layout

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.
